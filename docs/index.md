# AdCheck Documentation

[![Install AdCheck Extension](install-button.svg)](https://ggl.link/adcheck?utm_source=github&utm_medium=page)

Welcome to the AdCheck documentation! AdCheck is a lightweight, framework-free Manifest V3 Chrome extension designed for ad operations and developers to validate ad tag implementations on publisher websites. It provides real-time visibility into network requests, DOM elements, and custom script behaviors.

## Features Overview

AdCheck provides a suite of tools for robust and efficient ad checking:

- **[Side Panel Widget](features/widget.md)**: An in-page helper that provides instant feedback on the status of ad-related elements and network activities.
- **[Configuration Settings](features/settings.md)**: Define custom bundles, script names, DOM IDs, CSS classes, cookies, local storage keys, and window globals to track.
- **[Site Overrides](features/site-overrides.md)**: Visually pick elements on a page and inject custom HTML or scripts before, after, or inside them.
